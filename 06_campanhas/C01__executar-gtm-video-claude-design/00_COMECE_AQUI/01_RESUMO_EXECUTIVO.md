# Resumo Executivo

## Estratégia

- Categoria: sistema metodológico de execução.
- Problema: administrar a ferramenta tornou-se trabalho antes do trabalho.
- Big Idea: **O aplicativo desenhado para você sair dele.**
- Promessa: menos trabalho antes do trabalho.
- Princípio: **Organizar é função do sistema. Executar é função sua.**
- CTA: **Pare de organizar. Comece a executar.**

## Público

- Prioritário: profissional neurodivergente multiprojeto.
- Ampliado: founders, operadores, consultores, freelancers e knowledge workers sobrecarregados.

## Pilares

1. Clareza: saiba o que fazer agora.
2. Contexto: retome sem reconstruir mentalmente.
3. Método: IA organiza segundo critérios explícitos.
4. Menos fricção: o usuário não constrói o sistema para começar.
5. Transparência: evidência, prática e hipótese são diferenciadas.

## Sistema de campanha

O contraste recorrente é `ADMINISTRAR → P&B, estático, denso` versus `EXECUTAR → cor, movimento, foco`. O adversário é o trabalho operacional criado pelo sistema, não marcas concorrentes nem pessoas que precisam planejar.

## Primeiro frame/slide mestre

Todo storyboard, apresentação ou moodboard deve começar com:

`EXECUTAR APP`  
`Menos trabalho antes do trabalho.`  
`Organizar é função do sistema. Executar é função sua.`

O frame deve demonstrar a dicotomia visual antes de explicar funcionalidades.
