# Repository boundaries · review

## MAESTRO

Owns: agents, skills, prompts, workflows, plugins, MCP, tools, evals e specialties.

## BLUEPRINTS

Owns: produto, requisitos, AC, domínio, arquitetura, contratos e development packets.

## GOVERNANCE

Owns: autoridade, IDs, evidências, decisões, riscos e gates.

## ECOSYSTEM

Owns: código, runtime, infraestrutura, CI/CD, implantação e release.

Blueprint defines WHAT. Ecosystem implements HOW. Governance controls WHY / AUTHORITY / EVIDENCE. Maestro provides execution capabilities.

Contratos de design: DESIGN SOURCE → BLUEPRINT CONTRACT → ECOSYSTEM IMPLEMENTATION. Referências não criam segunda fonte da verdade.
