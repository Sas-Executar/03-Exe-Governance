# Evidências

Registre cada item no CSV com ID `EVD-AAAAMMDD-NNN` e documento relacionado; organize arquivos publicáveis em `<ID-documento>/<ID-evidencia>__<descricao>.<ext>`.

Informe o que a evidência comprova, sua data e versão examinada; conteúdo restrito deve permanecer em ambiente com acesso controlado.
