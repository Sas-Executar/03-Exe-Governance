# Programa SAS

Estrutura documental do Ecossistema SAS · Custo Cognitivo · Executar.

[Índice mestre](00_governanca/MASTER_INDEX.md) · [Guia de preenchimento e submissão](00_governanca/GUIA_DE_SUBMISSAO.md) · [Gates](02_lancamento/README.md)

## Comece aqui

1. Localize a área e o ID no índice mestre.
2. Preencha o modelo canônico em `00_documentos`, mantendo seu ID e caminho.
3. Armazene materiais de apoio no tópico/subtópico correspondente e vincule-os ao documento.
4. Registre a submissão para revisão conforme o guia, quando iniciar essa etapa.

## Estado canônico

Existem **23 áreas** e **46 documentos canônicos registrados**. D01–D16 preservam a estrutura anterior; D17–D23 foram adicionadas sem renumerar IDs existentes.

A taxonomia granular de tópicos e subtópicos permanece coberta para D01–D16. A decomposição de D17–D23 será feita em etapa posterior.

O repositório é público: não enviar dados pessoais, credenciais, contratos confidenciais ou evidências restritas; registrar apenas referências adequadas em ambiente com acesso controlado.

O documento anterior em `docs/governance` permanece como registro histórico; `00_governanca/MASTER_INDEX.md` define a estrutura canônica atual.
